# 正文优先：宽度拖拽与输入即预览

日期：2026-10-21。关联 [PR #19](https://github.com/TeaganRicardo/SteamCuratorHub/pull/19)、[#13](https://github.com/TeaganRicardo/SteamCuratorHub/issues/13)。

## 确认依据

用户已确认游戏工作台主结构，并在第二轮选择“正文优先，资料按需展开”，同时明确要求：

> 选择 2，允许拖拽宽度。另外确保输入即预览，只在复制时带上格式，无需切换预览和编辑。

这些要求已写入本分支 [REQUIREMENTS.md](../REQUIREMENTS.md)。这里记录落实后的交互和实现边界，不重复询问已确认的选择。

## 本版行为

- 进入写作先显示作者正文；资料和 AI 建议按需从右侧展开或收起。
- 游戏列表与资料面板的边界可拖拽调宽；键盘焦点在分隔条上时，用左右方向键调节。正文保留最小可用宽度，窄屏改为上下排列。
- 长评直接显示并编辑标题、粗体、斜体、列表和引用；工具栏在当前选择上生效。没有“预览/返回编辑”按钮，也不要求编辑 BBCode 源文本。
- 粘贴带排版的内容时，长评保留允许的语义格式，短评提取纯文字；脚本、嵌入对象和外部样式不会进入编辑内容。选区复制再粘贴回编辑区，不把相应的 BBCode 标记当作日常正文。
- 整篇“复制到 Steam”在复制时生成 BBCode，并独立组合当前唯一投稿群组的链接尾巴；正文内不追加尾巴，重复复制不会累加。编辑区内选中文字后复制，也按选择范围带出相应格式。
- 短评直接编辑纯文本，最多 199 个 Unicode 码点；复制不附带格式、尾巴或独立全文链接。超过限制保留作者原文并提示修改。
- 复制确实成功后才提示成功。嵌入预览没有剪贴板权限时，仅在复制动作后显示可手动复制的结果，不把格式文本变成日常编辑模式。
- 游戏、语言、长短评的内容分别保留。AI 建议应用前对照，正文新版本阻止旧建议直接覆盖；应用时保留上一版作者内容。
- 运行托盘持续可见，逐款单停；同游戏成就预览和示例写入不会重建运行集合，未知结果按游戏保留并先核对。

Steam 格式采用 BBCode 是对当前发布目标的工程解释。当前群组链接来自已给定的浮生评测、桃你欢心配置；正式尾巴模板仍按原需求由用户核对，本草图不新增模板认可。

## 运行与尝试

```sh
npm run prototype:ux -- --round=3
```

打开 `http://127.0.0.1:4319/`。前两轮各自入口仍保留为历史比较，本版只有已确认的正文优先布局。

1. 在排版后的正文直接输入，选择文字后点加粗、斜体、标题或列表；不进入其他预览模式。
2. 展开资料，拖拽正文与资料之间的分隔条；也可拖拽左侧游戏列表边界。继续编辑并切换游戏/语言，检查内容归属。
3. 点击“复制到 Steam”，在可接收文本的目标检查标题、强调、列表和单次群组尾巴；切换到短评后复制，检查正文不含尾巴或全文链接。
4. 生成建议后手改正文，对照区保留作者新版本并阻止旧建议直接应用；重新生成并应用后可以查看上一版。
5. 切到成就与统计执行固定示例预览/写入，在运行托盘单停一款。演示结果可在场景控制中切为未知，以检查核对入口。

## 验证与交付边界

本版本机通过 35 个桌面模块语法检查、241/241 完整离线测试（0 skip）。一次性 DOM 检查覆盖直接排版输入、没有预览切换、复制时生成标题/粗体/列表 BBCode、重复复制仅一个尾巴、短评纯文本及超限阻断、旧建议版本门禁、上一版保留、游戏草稿归属、单停隔离和指针调宽。补充检查确认长评粘贴保留允许的语义格式、去除脚本，短评粘贴提取纯文字。

浏览器已实际操作直接输入、选中文字并应用斜体，以及两处分隔条拖拽：资料 270 → 350 像素，游戏列表 160 → 200 像素。实际复制后粘贴核对了长评中的标题/粗体/斜体/列表/单次尾巴、短评的纯正文，以及选区复制结果 `[b][i]值得留意[/i][/b]`；没有以按钮状态代替粘贴结果。原生复制该选区后粘回长评，文字仍显示为粗斜体；粘进短评则只出现“值得留意”，没有格式标记。检查过程中正文与两款运行集合保留，最终格式操作只增加一次草稿版本。

此分支仍是可抛弃的交互原型。正文、宽度和操作均只使用本次草图内存；聊天宿主可记住宽度等界面状态，不保存草稿文本或凭据。服务只监听本机回环地址，页面没有外部 API 请求；复制只在用户动作后写入剪贴板。

本轮的具体机械检查、浏览器检查、最终提交与对应 CI 在 PR #19 记录；早期轮次的 CI 不用于声称当前 head 已验证。

正式接入时应保留当前生产工作区的账号/任务/语言/版本约束、AI 建议与草稿分离、备份恢复和发布内容冻结；已有 BBCode 草稿应转换为可编辑排版而保留语义。输入法组合输入、撤销、选择和工具栏焦点需要由正式编辑器自身维护。不能将本次原型的直接浏览器编辑命令当成正式编辑器的架构决定，也不能把示例复制当成实际 Steam 表单验收。
