## 工作流与验收

- 左侧以游戏任务选择上下文，右侧在当前游戏内使用运行、成就、研究写作和发布准备；顶部连接、查找和设置保持工作台外壳，底部并行运行常驻并可单独停止。
- 默认正文优先，资料按需展开；游戏列表和资料宽度可拖拽或键盘调整，窄窗口资料堆叠展示。
- 长评输入区直接排版，不切换编辑与预览。保留旧草稿 BBCode、独立语言、CAS 保存与账号归属。复制组合群组尾巴一次，短评保持纯文本并独立保存全文链接。
- 来源、AI 建议和作者草稿分开；应用建议仍检查任务、语言与基础版本，迟到结果和失败不能覆盖作者修改。
- 连接、Guard、恢复和有界重连阶段可见。保存会话恢复为首选，明确重新认证才显示密码；恢复连接不恢复运行。
- 游戏查找与详情浏览保留作者上下文；已有任务直接打开，新任务选择唯一投稿群组。累计目标与本次期限分开，运行与同游戏成就操作可并用。
- 未知原生写入先重新读取，展示返回值，再独立确认已核对；账号或操作变化使核对失效，确认不伪造自动核实。
- 备份先验证并对照，停止活动操作后单独恢复；预览期间作者数据变化会阻止旧恢复。凭据、当前账号和服务设置独立保留，导入证据降为未核实。
- 长短评发布版本分别冻结，修改后旧内容不能再填表；未知或导入结果未核对前不重复准备。本人提交、人工确认和长评回读来源分别记录。
