# Steam Curator Hub

面向个人 Steam 鉴赏家的桌面工作台。目标支持 macOS 与 Windows，首版优先 macOS，目前处于需求对齐与历史原型接收阶段。

## 项目基线

本 GitHub 仓库是跨 ChatGPT Chat Mode 线程、跨 Project 协作的唯一项目状态基线。对话记忆不作为实现完成或需求确认的证据。已合并内容代表接受的基线；未合并分支与 PR 必须标注为进行中。

当前尚无新版本实现、构建产物或实机验证结果。

## 用户已明确的目标

- 单一 Steam 账号，支持多个鉴赏家群组。
- Steam 库绑定、游戏搜索、商店个人评论查看、翻译与 AI 格式整理。
- 个人长评撰写、格式处理与发布，支持按群组选用特定尾巴。
- 从长评总结、删减生成 200 字以下的鉴赏家短评；中文字符、英文字母与符号均计 1 字。边界值、空白及特殊 Unicode 字符的细则待确认。
- 鉴赏家短评关联个人长评链接；在可行时集成鉴赏家发布能力。
- 模拟运行游戏累计时长，以及类 SAM 的成就管理，均为必要功能。
- 成就搜索、全球解锁百分比展示，以及包括百分比在内的多种排序。
- 首轮优先对齐需求、调优流程；最终架构和技术栈尚未确定。

## 历史原型

用户提供了 Windows 本机历史原型，尚未上传或审阅。该原型不是多平台实现，接收后作为需求和实现参考；其既有行为不自动等同于已确认的新产品需求。

公开上传前检查凭据、登录会话、个人数据、依赖目录与构建产物，仅导入适合公开的参考材料。尚未选定开源许可证。

## 未决事项

- 同一游戏是否向多个鉴赏组投稿，以及长评尾巴的选择规则。
- Mac 首版是否必须管理未安装、无 Mac 版本的游戏。
- AI 使用应用内 API，还是通过外部 ChatGPT 处理后导回。
- Mac 成就写入与时长累计的实际可用性，特别是 Apple Silicon 与 Windows-only 游戏。
- 个人长评及鉴赏家短评发布方式、登录状态处理与发布结果核实。
